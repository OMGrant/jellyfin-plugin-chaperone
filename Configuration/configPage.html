Chaperone

Fills in missing parental ratings for music (Deezer), movies & shows (TMDb), and anime (MyAnimeList) so parental controls work across the whole library.

Library scan

Run a one-off pass over your whole library, filling in ratings for items that don't have one yet (or all items when "Overwrite existing ratings" is on). Your current settings are saved first. Progress appears under Dashboard → Scheduled Tasks.

Settings

Rating proposals (MCP)

Chaperone is an MCP server at /Chaperone/mcp on this Jellyfin (admin API keys only). An AI model — Claude, a local model, any MCP client — can list unrated items, read their details and lyrics, and propose a rating with evidence; Chaperone checks that quoted evidence really appears on the cited page. Give each client its own API key (Dashboard → API Keys) so you can tell them apart and revoke one on its own.
